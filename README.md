# Annotator Privacy Redactor

A tool for redacting sensitive information from annotated documents while preserving the integrity of the annotation data.

## Features

- Privacy-focused redaction of sensitive data
- Maintains annotation structure and metadata
- Simple and intuitive interface

## Installation

Clone the repository and open the HTML files in your web browser.

```bash
git clone https://github.com/prasannat05/Annotator-Privacy-Redactor.git
```

## Usage

Open the HTML files in your preferred web browser to use the annotation and redaction tools.
